Escher Tagger

A bookmarklet that adds a panel to any Escher map: select nodes, then set values, highlight, or annotate them, and export the result.

Drag this button to your bookmarks bar:

Escher Tagger

Firefox: if dragging doesn't work, right-click the button and choose Bookmark Link.

Use

  1. Open an Escher map (a standalone HTML from jt_escher, escher.github.io, or any page that embeds Escher).
  2. Click the bookmark. A panel appears at the top right; click the bookmark again to hide or show it.
  3. In Escher, switch to Select mode (Edit menu, or v), then click, shift-click, or drag a box over nodes.
  4. Type a value and press Set, or press Highlight. Notes can also be placed on the map as text labels.
  5. Export JSON saves values and notes; Import loads them back. Use Escher's Map > Save map JSON to keep the text labels.
