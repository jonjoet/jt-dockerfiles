How matching and export work

Features are grouped by sequence ID, feature type, strand, and exact coordinates. Names, IDs, sources, scores, attributes, and CDS phase may differ within a group. A group is a prompt for review, not proof that the annotations are interchangeable.

  • All features start checked. Uncheck unwanted copies, or choose Keep only this within a duplicate group. Every selection change can be undone.
  • Rows sharing a GFF3 ID are treated as one feature. All its segments are retained or removed together; multipart features match only when their complete segment sets match.
  • Export removes only unchecked feature lines. Retained lines, IDs, attributes, ordering, comments, directives, line endings, and any embedded FASTA are preserved. Attributes are not merged or rewritten.
  • Export is blocked if retained features have missing Parent or Derives_from references. You can restore required features or remove the referring features. Existing missing references also need correction in the source file.
  • FASTA is optional and is used only for sequence lengths and ID checks. Circular features extending beyond the FASTA length are shown wrapped in the overview. No sequence bases are changed.
  • This file has no external dependencies or network access. Files and selections stay in this tab and are lost when it closes. Download your cleaned GFF3 before leaving.
